# 剪影画廊 · Silhouette Gallery

根据 `草图.png` 的布局实现，并扩展为「更换画框照片 → 自动生成白色剪影」的可交互页面。

## 功能

- **更换画框内容**：右上角齿轮进入设置，可为任意画框更换照片；模型自动识别主体、剥离背景、清除噪点并生成白色剪影 PNG，也可随时恢复默认。
- **悬停快速预览 / 点击查看完整原图**：默认显示白色剪影；悬停或键盘聚焦可快速预览，点击画框可在灯箱中查看未裁切的完整原图。
- **固定四幅画框**：画框数量固定，不可新增或删除。
- **自定义页面**：右上角齿轮可修改主标题、副标题、背景颜色、背景图片与画框内容；设置保存在本机浏览器（localStorage），下次打开自动生效。
- **本地隐私**：推理完全在浏览器内完成，图片不会上传到任何服务器。

## 快速开始

双击 `启动.bat` 即可。它会：

1. 自动探测并优先使用本机已有的 Python / Node.js；
2. 都没有时，自动改用 **Windows 自带的 PowerShell** 启动内置静态服务器——**不需要安装或下载任何环境**；
3. 如果 8000 端口被占用，会自动改用 8001~8010 中的空闲端口；
4. 服务器就绪后自动打开浏览器，命令窗口会一直保留（关闭窗口即停止服务器），不会再“闪一下就不见”。

也可以手动用任意静态服务器打开本目录：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

### 给朋友使用

1. 在 GitHub 仓库页面点击 **Code ▾ → Download ZIP**，下载后**先解压全部文件**（不要直接在压缩包里双击）。
2. 进入解压后的文件夹，双击 `启动.bat`。
3. 等待片刻，浏览器会自动打开页面；命令窗口会保持打开（显示服务器地址），**关掉这个窗口就停止服务器**。
4. 如果页面打不开，查看同目录下的 `startup_log.txt`，或把窗口里的英文提示发给开发者。

> 如果朋友想完全离线使用，也可以不启动服务器，直接双击 `index.html` 查看页面（更换照片时的 AI 模型需要联网下载一次）。

> 首次更换画框照片时需要下载约 42MB 的 AI 模型（RMBG-1.4）并完成初始化，视网络与设备情况等待 1~3 分钟；之后浏览器会缓存模型，同一标签页内再处理其他照片就很快了。下载源默认依次尝试 huggingface.co 与 ModelScope 国内镜像，国内网络会自动走镜像。推理由 onnxruntime 的 WebAssembly 在浏览器本地完成（部分环境会尝试 WebGPU 加速，不支持时自动回退）。

## 技术原理

1. 上传图片后，用浏览器内置 Canvas 预处理为模型输入（1024×1024，归一化）。
2. [onnxruntime-web](https://github.com/microsoft/onnxruntime) 在浏览器本地运行 [RMBG-1.4](https://huggingface.co/briaai/RMBG-1.4) 分割模型，输出每个像素属于主体的 alpha 蒙版。
3. 确定主体：蒙版做对比增强与阈值二值化，保留最大连通区域（清除背景噪点），计算主体包围盒。
4. 剪影化：裁剪主体包围盒（带边距），居中放入与画框同比例的画布，填充纯白并保留 alpha，得到白底透明背景的剪影 PNG。
5. 页面默认画框使用 `mask-mode: alpha` 的剪影遮罩（`images/*-sil.svg`，透明背景 + 白色主体）；更换后的剪影直接作为背景图展示。点击画框会在灯箱中显示未裁切的完整原图。

原有四张示例卡片保留（深色背景 + 明亮主体的高对比 SVG），作为默认画廊内容；每张另有独立的剪影遮罩文件。

## 自定义

- 右上角齿轮打开面板：
  - **主标题 / 副标题**：修改后即时生效，浏览器标签页标题同步更新。
  - **背景颜色**：预设色板 + 自定义取色。
  - **背景图片**：选择后自动缩放为最长边 1920px 的 JPEG 并保存在 localStorage。
  - **画框内容**：每个画框可更换照片（自动识别主体并生成白色剪影，原图压缩为最长边 1280px 的 JPEG 后保存）或恢复默认。
  - **恢复默认**：一键还原初始标题、浅灰背景与默认画框。
- 设置仅保存在当前浏览器，换浏览器 / 清缓存后恢复默认。

## 文件结构

```text
index.html        页面结构
style.css         样式：画廊、画框设置、自定义面板
script.js         交互：分割推理、剪影生成、画框内容设置、持久化
images/           四张示例插画（SVG）+ 对应的剪影遮罩（-sil.svg）
草图.png          原始布局草图（未改动）
tools/            开发验证脚本（Node）
tools/serve.ps1   内置 PowerShell 静态服务器（零依赖兜底，任何 Windows 都能跑）
启动.bat          本地静态服务器启动器（自动探测 Python / Node，没有则用内置 PowerShell 服务器）
server.js         Node 静态文件服务器（启动.bat 兜底用）
.gitattributes    保证 .bat 以 CRLF 换行提交，避免下载后命令框异常
```

# 剪影画廊 · Silhouette Gallery

根据 `草图.png` 的布局实现，并扩展为「更换画框照片 → 自动生成白色剪影」的可交互页面。

## 功能

- **更换画框内容**：右上角齿轮进入设置，可为任意画框更换照片；模型自动识别主体、剥离背景并生成白色剪影 PNG，也可随时恢复默认。
- **悬停查看原图**：默认显示白色剪影，鼠标悬停或键盘聚焦后淡入原图。
- **固定四幅画框**：画框数量固定，不可新增或删除。
- **自定义页面**：右上角齿轮可修改主标题、副标题、背景颜色、背景图片与画框内容；设置保存在本机浏览器（localStorage），下次打开自动生效。
- **本地隐私**：推理完全在浏览器内完成，图片不会上传到任何服务器。

## 快速开始

双击 `启动.bat`（需要本机装有 Python 或 Node.js），或手动用任意静态服务器打开本目录：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

> 首次更换画框照片时需要下载约 42MB 的 AI 模型（RMBG-1.4）并完成初始化，视网络与设备情况等待 1~3 分钟；之后浏览器会缓存模型，同一标签页内再处理其他照片就很快了。下载源默认依次尝试 huggingface.co 与 ModelScope 国内镜像，国内网络会自动走镜像。推理由 onnxruntime 的 WebAssembly 在浏览器本地完成（部分环境会尝试 WebGPU 加速，不支持时自动回退）。

## 技术原理

1. 上传图片后，用浏览器内置 Canvas 预处理为模型输入（1024×1024，归一化）。
2. [onnxruntime-web](https://github.com/microsoft/onnxruntime) 在浏览器本地运行 [RMBG-1.4](https://huggingface.co/briaai/RMBG-1.4) 分割模型，输出每个像素属于主体的 alpha 蒙版。
3. 蒙版放大回原图尺寸，填充纯白并保留 alpha，得到白底透明背景的剪影 PNG。
4. 页面复用 `mask-mode: luminance` 的默认卡片样式；更换后的剪影直接作为背景图展示。

原有四张示例卡片保留（深色背景 + 明亮主体的高对比 SVG），作为默认画廊内容。

## 自定义

- 右上角齿轮打开面板：
  - **主标题 / 副标题**：修改后即时生效，浏览器标签页标题同步更新。
  - **背景颜色**：预设色板 + 自定义取色。
  - **背景图片**：选择后自动缩放为最长边 1920px 的 JPEG 并保存在 localStorage。
  - **画框内容**：每个画框可更换照片（自动生成白色剪影，原图压缩为最长边 1280px 的 JPEG 后保存）或恢复默认。
  - **恢复默认**：一键还原初始标题、浅灰背景与默认画框。
- 设置仅保存在当前浏览器，换浏览器 / 清缓存后恢复默认。

## 文件结构

```text
index.html        页面结构
style.css         样式：画廊、画框设置、自定义面板
script.js         交互：分割推理、剪影生成、画框内容设置、持久化
images/           四张示例插画（SVG）
草图.png          原始布局草图（未改动）
tools/            开发验证脚本（Node）
启动.bat          本地静态服务器启动器
```
